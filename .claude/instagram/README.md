# Instagram agent skills

Thirteen `/ig-*` skills in `.claude/skills/`, vendored from
https://github.com/Jakeschincariol/instagram-agent-skill (MIT, commit d03c56b).

The skills read your voice profile from `~/.claude/instagram/voice.md`.
Copy `voice.md.template` there and fill it in, or give Claude three of your
reels and ask it to write one.
